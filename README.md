
# 🦀 Rust.Hub: The Systems Engineering Lab
**By Southwest AI Labs**

Rust.Hub no es un tutorial; es un entorno de simulación de alta fidelidad diseñado para ingenieros que buscan el rango de **Distinguished Engineer (L5)**.

## 🚀 Vision
Nuestra misión es democratizar el conocimiento de la arquitectura de sistemas profundos mediante visualizaciones en tiempo real, análisis por IA y "Proof of Work" persistente en GitHub.

## 🛠️ Tech Stack
- **Core**: React 18 + TypeScript + Tailwind CSS.
- **Engine**: Google Gemini 3.0 Pro (Mastery Reasoning).
- **Visuals**: Three.js (Backgrounds) + Mermaid.js (Diagrams) + Custom Memory Visualizer.
- **Persistence**: GitHub API as a decentralized DB (Neural Forking).
- **Future**: Rust via WebAssembly for in-browser lifetime checking.

## 💎 Key Features
- **Neural Mastery Tests**: Retos L5 generados dinámicamente.
- **Copilot Architectural Score**: Evaluación de calidad de código nivel Staff.
- **Memory HUD**: Visualizador de Stack/Heap interactivo.
- **PWA Ready**: Funciona offline para sesiones de estudio profundo.
