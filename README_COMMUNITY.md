## 🚀 Getting Started

### Prerequisites
- **Node.js** 18+
- **npm** or **yarn**
- A modern browser (Chrome, Firefox, Safari, Edge)

### Quick Start

```bash
# Clone the repository
git clone https://github.com/yourusername/rust-patterns-visuals.git
cd rust-patterns-visuals

# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:5173 in your browser
```

### Build for Production

```bash
npm run build
npm run preview
```

## 📚 Learning Paths

### Beginner Path (Start Here)
1. **Option & Result** - Error handling fundamentals
2. **Basic Control Flow** - match expressions and conditionals
3. **String & Vec Basics** - Working with Rust's core collections

### Intermediate Path
1. **Iterators vs Loops** - Functional programming in Rust
2. **Lifetime Concepts** - Understanding Rust's reference model
3. **Trait Deep-Dive** - Polymorphism and abstraction

### Advanced Path (L5 Mastery)
1. **Unsafe Rust & FFI** - Low-level systems programming
2. **Async & Concurrency** - Building performant concurrent systems
3. **Memory Optimization** - Heap allocation, SIMD, and performance
4. **Kernel & EBPF** - Linux kernel programming
5. **Distributed Systems** - Building resilient architectures

## 🐛 Troubleshooting

### Platform won't load?
```bash
# Clear cache and reinstall
rm -rf node_modules package-lock.json
npm install
npm run dev
```

### Slow performance?
- Check your internet connection
- Disable background extensions
- Increase available RAM
- Use a modern browser

### Quiz not submitting?
- Ensure you're connected to the internet (for AI evaluation)
- Check GitHub token settings if using persistence

For more help, check our [FAQ](docs/FAQ.md) or open an [issue](https://github.com/yourusername/rust-patterns-visuals/issues).
