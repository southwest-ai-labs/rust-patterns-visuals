
# 🗺️ Rust.Hub Strategic Roadmap

## Phase 1: Real-Time Verification (Current)
- [ ] **WASM Borrow Checker**: Integrar `rustc` o un linter ligero vía WebAssembly para feedback instantáneo sin salir de la web.
- [ ] **Thread Visualization**: Expandir el Chaos Simulator para soportar arquitecturas Actor-Model.

## Phase 2: Community & Reputation
- [ ] **Cracks Wall**: Feed interactivo donde usuarios pueden dar "Like" (Verify) a soluciones de otros, otorgando MMR de mentoría.
- [ ] **Neural Pair Programming**: Ferris escribiendo sugerencias de código en tiempo real usando Gemini Streaming.

## Phase 3: Certification & Proof of Talent
- [ ] **Signed Certificates**: Generar archivos `.sig` usando Web Crypto API que los reclutadores puedan validar.
- [ ] **Job Board Integration**: Conectar directamente con empresas que buscan desarrolladores con alto MMR verificado en Rust.Hub.
