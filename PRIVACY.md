
# Política de Tratamiento de Datos Públicos

**Rust.Hub** adopta una arquitectura de "Transparencia por Diseño".

1. **Datos de Identidad**: Solo requerimos tu usuario de GitHub. Puedes usar un **Apodo (Nickname)** para el registro visual en la Leaderboard, pero la vinculación técnica siempre será con tu perfil de GitHub.
2. **Naturaleza de los Datos**: Dado que el proyecto requiere un **Fork Público** del usuario para su funcionamiento, todo tu avance, código de solución y resultados de pruebas son públicos por definición de la plataforma GitHub.
3. **Recopilación Centralizada**: Semanalmente, un workflow de Southwest AI Labs revisará los forks públicos conectados para recopilar las pruebas personalizadas (.md). Estos datos se utilizan para:
   - Alimentar el módulo de "Community Insights".
   - Generar discusiones en GitHub Discussions.
   - Refinar los prompts de evaluación de la IA.
4. **Sin Datos Privados**: Nunca solicitaremos correos electrónicos, contraseñas o datos de pago dentro de la aplicación.
